# 🧮 Counter App (React)

### 📅 Day 3 – React Basics
Simple counter app using **useState** and **event handling**.

---

### 🚀 Features
- Increment, decrement, and reset the counter  
- Dynamic display using React state  
- Responsive layout and clean design  

---

### 🧠 Concepts used
- `useState()` hook  
- Event handling (`onClick`)  
- JSX dynamic rendering (`{count}`)
